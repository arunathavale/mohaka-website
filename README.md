# Mohaka Skincare website

Prototype storefront for Mohaka Skincare, herbal luxury skincare rooted in Ayurveda.

- `index.html` is the whole site in one file (images are embedded). Open it in any browser.
- `light-version.html` is the earlier light color scheme.
- `assets/` holds the original logo and product posters.

Status: prices, full ingredients and how-to-use text are placeholders. Checkout is not connected yet.
